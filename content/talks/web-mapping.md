## Talk Abstract


This talk outlines the modern mapping ecosystem, allowing the embedding of
custom, fully self-hosted interactive maps into web applications without
relying on complex server architecture or SaaS providers. We will walk
through a complete end-to-end stack: extracting regional OpenStreetMap
data from open global builds using the Protomaps ecosystem, serving the
map data using the single-file pmtiles format and HTTP Range Requests,
and using MapLibre GL JS within a modern Nuxt application to render the
base map alongside our own interactive geospatial data.
